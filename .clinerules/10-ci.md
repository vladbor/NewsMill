# CI/CD Rules

## Pre-commit Checks
- Install dependencies `uv sync`
- Run `ruff format .` to format all Python files before committing.
- Run `ruff check .` to lint all Python files and fix all warnings.
- Run `pytest -v` to ensure all tests pass.
- Verify no new warnings or errors are introduced.

## Smoke Test
- Before running the full CI pipeline, start the application locally to verify it boots successfully.
- Perform a health check of app if it possible.
- Stop the application after the smoke test completes.
- Fail the pipeline immediately if the smoke test fails.

## CI Pipeline (GitHub Actions / GitLab CI)
- Use Python 3.12 as the runtime version.
- Install dependencies with `uv sync`.
- Run linting step: `ruff check .`
- Run formatting check step: `ruff format --check .`
- Run tests step: `pytest -v`
- Fail the pipeline if any step fails.

## Configuration
- Store CI configuration in `.github/workflows/` (GitHub Actions) or `.gitlab-ci.yml` (GitLab).
- Do not commit secrets or tokens — use CI secrets/variables.
- Cache `uv` dependencies between runs to speed up pipelines.

## Branch Strategy
- Keep the `main` branch always green — all checks must pass before merging.
- Use feature branches for new work.
- Squash merge commits to keep history clean.
